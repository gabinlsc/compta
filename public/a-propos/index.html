À propos

Compta by glsc est édité par Gabin Lescoat, entrepreneur individuel (EI) et fondateur de StudioGLSC, un studio web en Bretagne.

J’ai construit ces outils parce que les démarches d’un indépendant sont souvent plus compliquées qu’elles ne devraient l’être, et que beaucoup de simulateurs en ligne demandent un compte ou collectent des données. Ici, rien de tout cela : les calculs se font dans votre navigateur.

Le projet est ouvert

Le code source est public et sous licence MIT : github.com/gabinlsc/compta. Si vous trouvez une erreur dans un chiffre ou un calcul, écrivez-moi via la page Contact.

Ce que ce site n’est pas

Ce n’est pas un cabinet comptable ni un conseil juridique ou fiscal. Les outils donnent des estimations indicatives à partir de sources officielles citées sur la page Sources.
